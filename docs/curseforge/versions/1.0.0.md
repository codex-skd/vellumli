<h2>v1.0.0 - First stable release (Minecraft 1.21.1)</h2>

<p>First stable release of Vellumli for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>
(Java 21). It consolidates the <code>0.0.0-beta.1</code> &rarr; <code>0.0.0-beta.2</code> line with
no further code changes. This build has been running in a full modded-server pack as a guidebook
dependency for other mods.</p>

<h3>What the 1.21.1 line brought</h3>
<ul>
<li><strong>Re-fork from upstream Patchouli 1.21.x</strong> (Vazkii / williewillus,
CC BY-NC-SA 3.0), flattened to a single NeoForge module and rebranded to the Vellumli identity
(package <code>vazkii.patchouli</code> &rarr; <code>com.skd.vellumli</code>, modid
<code>patchouli</code> &rarr; <code>vellumli</code>).</li>
<li><strong>Feature parity with the 26.2 line</strong>: the data-driven book engine, all built-in
page types (text, crafting / smelting / smithing / blasting / campfire, image, spotlight, entity,
relations, link, quest), custom components and templates, the full book GUI (landing, categories,
search, bookmarks, history), advancement gating, and the JEI subtype interpreter so each mod's book
is a distinct searchable ingredient. The multiblock preview system is not included (matches the
26.2 scope; the <code>api</code> stubs are kept for source compatibility).</li>
<li>26.2 &rarr; 1.21.1 API reversions: <code>Identifier</code> &rarr; <code>ResourceLocation</code>,
<code>GuiGraphicsExtractor</code> &rarr; <code>GuiGraphics</code>,
<code>extractRenderState()</code> &rarr; <code>render()</code>,
<code>pushMatrix()/popMatrix()</code> &rarr; <code>pushPose()/popPose()</code>; the
<code>completion</code> model predicate re-registered via <code>ItemProperties.register()</code>;
<code>BookModel</code> reworked to the 1.21.1 baked-model form.</li>
<li><strong>Spanish (<code>es_es</code>) locale</strong> completed (13 missing keys).</li>
</ul>

<h3>Notes</h3>
<blockquote>Dependency-free by design. Verified: <code>./gradlew clean build</code> is green;
<code>./gradlew runServer</code> reaches <code>Done</code> with both server-side accessor mixins
applied. Shares this CurseForge project with the 26.2 line &mdash; pick the file that matches your
Minecraft version.</blockquote>
