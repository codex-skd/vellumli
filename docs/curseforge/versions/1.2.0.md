<h2>v1.2.0 - JEI Subtype Support &amp; Demo Book Removal</h2>

<h3>Feature</h3>
<ul>
<li><strong>Optional JEI integration</strong>: registers an <code>ISubtypeInterpreter</code> for <code>vellumli:guide_book</code> keyed on the <code>vellumli:book</code> component, so JEI treats each mod's book as its own distinct, searchable ingredient with its own display name instead of collapsing every Vellumli book into a single unsearchable entry.</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Removed the bundled "Vellumli Demo Book"</strong>: development/example content (book id <code>vellumli:demo</code>) that wasn't meant to reach players — it was showing up in every world's creative inventory and JEI.</li>
</ul>
