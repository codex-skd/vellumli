<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Vellumli for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). Same book engine as the 26.2 build.</p>

<h3>About this build</h3>
<ul>
<li><strong>Re-fork, not a back-port</strong>: rebuilt from the upstream <a href="https://github.com/VazkiiMods/Patchouli">Patchouli</a> 1.21.x sources (Vazkii / williewillus, CC BY-NC-SA 3.0), flattened to one NeoForge module and rebranded to the Vellumli identity.</li>
<li><strong>Feature parity with 26.2</strong>: the data-driven book engine, all built-in page types, custom components and templates, the book GUI (landing / categories / search / bookmarks), advancement gating, and the JEI subtype interpreter that makes each mod's book a distinct searchable ingredient.</li>
<li><strong>Dependency-free</strong>: no required dependencies. JEI is optional (searchable-book compat only).</li>
<li><strong>Not included</strong>: the multiblock structure-preview system (matches the 26.2 line's scope).</li>
</ul>
