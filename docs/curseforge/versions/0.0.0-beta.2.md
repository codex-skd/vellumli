<h2>v0.0.0-beta.2 - Build fixes and mod icon</h2>

<h3>Fix</h3>
<ul>
<li><strong>NeoForge 26.1 to 26.2 API breakage</strong>: resolved all compile errors found while porting Patchouli — <code>Minecraft.screen</code> is now <code>Minecraft.gui.screen()</code>, advancement predicate classes moved from <code>advancements.criterion</code> to <code>advancements.predicates</code>, <code>getToastManager()</code> is now <code>gui.toastManager()</code>. Removed a mixin targeting a rendering class no longer present in 26.2.</li>
<li><strong>Mod failed to load</strong>: the packaged <code>neoforge.mods.toml</code> was not being processed due to a stale template path inherited from the shared mod skeleton. Fixed and verified the mod now loads cleanly in a real client, including the data-driven demo book.</li>
<li><strong>JAR naming</strong>: now follows the project convention (<code>vellumli-26.2-neoforge-&lt;version&gt;.jar</code>).</li>
</ul>

<li>Mod icon.</li>
</ul>
